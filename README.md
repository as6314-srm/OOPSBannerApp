# OOPS Banner App (Java)

This project demonstrates the evolution of a Java console application using Object-Oriented Programming concepts and structured Git workflow.  
UC1 prints the text "OOPS" to the console using basic Java syntax.  
UC2 extends the program to display OOPS as an ASCII banner using print statements.  
UC3 refactors the banner implementation using `String.join()` for improved readability and memory efficiency.  
The project highlights code refactoring and incremental software development practices.  
Implemented using Java in VS Code on macOS.  
Version control and feature development were managed using Git and GitHub branching.  
Each use case was developed in separate feature branches and merged into the dev branch.  
This project helped strengthen Java fundamentals and professional Git workflow understanding.
